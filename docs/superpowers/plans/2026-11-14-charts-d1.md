# Charts semanais no D1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Os 5 charts semanais (Hot 100, Spotify, Apple Music, Digital Sales, YouTube) e seus rankings por país passam a vir do D1, alimentado pela aba DADOS via push semanal do Apps Script, mantendo o contrato de `/api/charts`.

**Architecture:** Funções puras (parse, validação, movimento, distribuição por país, resolução de artistas) em `backend/src/services/chartsD1/`, testadas com `bun test`. Um repositório SQL fino sobre `D1DatabaseLike` grava/consulta. Um endpoint `POST /api/charts/ingest` recebe a semana; `chartsController.ts` passa a ler do D1 para esses 5 charts. Ranking por país é **calculado na leitura** a partir das linhas gravadas (ver "Desvio do spec").

**Tech Stack:** TypeScript, Cloudflare Workers + D1 (`CATALOGO_DB`), `bun:test` + `bun:sqlite` (adaptador D1 de teste), Google Apps Script.

**Spec:** `docs/superpowers/specs/2026-11-14-charts-d1-design.md`

## Desvio do spec (aprovar com o usuário antes de executar)

O plano gratuito do D1 grava no máximo **100 mil linhas/dia** (índices contam).
Guardar o Top 50 de 81 países × 3 plataformas são ~12 mil linhas por semana,
**~3,1 milhões** no histórico de 256 semanas — inviável no gratuito. Por isso:

1. **Países são calculados na leitura** (uma semana = ~100 músicas × 81 países,
   milissegundos), a partir das linhas de `chart_semana`, que já guardam os
   artistas congelados daquela semana. Não existe tabela `chart_pais_semana`.
   Consequência: se pesos, bônus ou nacionalidade de um artista mudarem, o
   ranking por país de semanas **antigas** também muda.
2. **iTUNES não é importado** (encerrado, não aparece na tela) — economiza
   17,6 mil linhas.
3. **Carga inicial retomável em lotes diários**: ~103 mil linhas × (tabela +
   1 índice) ≈ 210 mil escritas → o script grava até 45 mil linhas por execução
   e pula semanas já carregadas; rodar em ~3 dias (ou de uma vez num plano pago).

## Global Constraints

- Fonte única dos 5 charts: aba DADOS (colunas A..L: CHART, DATA dd/mm/aaaa, POSIÇÃO, MÚSICA "Artista - Título", PONTOS/VENDAS SEMANA pt-BR "1.175", VENDAS GERAIS, vazia, ARTISTA 1..5).
- Charts: `BILLBOARD HOT 100`, `SPOTIFY`, `APPLE MUSIC`, `DIGITAL SALES`, `YOUTUBE`. Países só em `SPOTIFY`, `APPLE MUSIC`, `YOUTUBE`.
- Status visíveis: `↑`, `↓`, `=`, `NEW` (reentrada conta como `NEW`).
- Bônus de nacionalidade padrão `0.20`; Top `50` por país; regra B (soma dos países + resto = total global).
- Artistas: H–L da DADOS → catálogo `musicas` (D1) → extração do título.
- Capa: `musicas.capa_url` (single vence faixa de álbum) → `artista_info.foto` → `""`. Gênero: `musicas.genero`.
- O Worker nunca lê a planilha EMPIRE - CHARTS.
- Envio semanal: tudo ou nada; reenvio da mesma data substitui.
- Contrato de `/api/charts` inalterado (mesmos campos: `pos, tit, val, valTotal, art, st, capa, style`; países `pais, pos, tit, val, mes, art, capa, st`).
- Regras de botões/tabs do `CLAUDE.md` para qualquer UI tocada.
- App roda no Cloudflare Workers (nada de Telegram).

## Review Focus

1. Título da DADOS com grafia diferente do catálogo (acentos, "feat." sem parênteses, maiúsculas) — deve casar via `normalizarTitulo`; teste em Task 3.
2. Música com artistas de dois países (ex.: Brasil + EUA) — os dois ganham bônus e a soma ainda fecha no total; teste em Task 2.
3. Primeira semana de um chart (Apple Music 20/01/2022, Digital Sales 11/04/2025) — todo mundo `NEW`, sem erro por falta de semana anterior; teste em Task 2.
4. Envio semanal com um chart faltando, posição repetida ou duas datas — recusado sem gravar nada; teste em Task 4.
5. `getFilters` de um chart ainda vazio no D1 — cai no fallback da planilha em vez de tela vazia; teste em Task 5.

### Task 2: Movimento e distribuição por país (funções puras)

**Files:**
- Create: `backend/src/services/chartsD1/movimento.ts`, `backend/src/services/chartsD1/paises.ts`
- Test: `scripts/charts-d1.test.ts`

**Interfaces:**
- Produces:
  - `interface HistoricoMusica { tituloNorm: string; posAnterior: number | null; peak: number; semanas: number; semanasN1: number }` (histórico **antes** da semana atual; `posAnterior` = posição na semana imediatamente anterior do mesmo chart, `null` se não esteve).
  - `calcularMovimento(pos: number, h: HistoricoMusica | undefined): { status: "↑"|"↓"|"="|"NEW"; posAnterior: number | null; peak: number; semanas: number; semanasN1: number }` — sem histórico ou `posAnterior === null` → `NEW`; peak = min(h.peak, pos); semanas = h.semanas + 1; semanasN1 += pos === 1.
  - `type Pesos = Map<string /*pais*/, number /*fração, 0.072*/>`
  - `fatiasPorPais(pesos: Pesos, nacionalidades: Set<string>, bonus: number): Map<string, number>` — regra B: `w[c] = pb[c] + (c ∈ nac ? bonus : 0)`; `resto = max(0, 1 − Σpb)`; `share[c] = w[c] / (Σw + resto)`.
  - `interface MusicaParaPais { tituloNorm: string; titulo: string; artistaPrincipal: string; valor: number; nacionalidades: Set<string> }`
  - `rankingPais(musicas: MusicaParaPais[], pesos: Pesos, pais: string, bonus: number, top: number): { pos: number; tituloNorm: string; titulo: string; art: string; val: number }[]` — valor = `round(valor × share[pais])`, ordena desc, empate por `tituloNorm`, corta em `top`.

```ts
test("movimento", () => {
  expect(calcularMovimento(5, undefined)).toEqual({ status: "NEW", posAnterior: null, peak: 5, semanas: 1, semanasN1: 0 });
  const h = { tituloNorm: "x", posAnterior: 3, peak: 2, semanas: 4, semanasN1: 0 };
  expect(calcularMovimento(1, h)).toEqual({ status: "↑", posAnterior: 3, peak: 1, semanas: 5, semanasN1: 1 });
  expect(calcularMovimento(7, h).status).toBe("↓");
  expect(calcularMovimento(3, h).status).toBe("=");
  expect(calcularMovimento(3, { ...h, posAnterior: null }).status).toBe("NEW"); // reentrada
});
test("fatias: soma fecha em 1 com resto, com Σ>1 e com dupla nacionalidade", () => {
  const soma = (m: Map<string, number>, resto: number) => [...m.values()].reduce((a, b) => a + b, 0) + resto;
  const p1: Pesos = new Map([["BRASIL", 0.072], ["ESTADOS UNIDOS", 0.1845]]); // Σ<1
  const f1 = fatiasPorPais(p1, new Set(), 0.2);
  expect(f1.get("BRASIL")).toBeCloseTo(0.072);
  const f2 = fatiasPorPais(p1, new Set(["BRASIL", "ESTADOS UNIDOS"]), 0.2);
  expect(f2.get("BRASIL")!).toBeGreaterThan(0.072);
  expect(soma(f2, (1 - 0.2565) / (0.2565 + 0.4 + (1 - 0.2565)))).toBeCloseTo(1);
  const p3: Pesos = new Map([["A", 0.7], ["B", 0.5]]); // Σ>1 (como YouTube 119,96%)
  const f3 = fatiasPorPais(p3, new Set(), 0.2);
  expect(f3.get("A")! + f3.get("B")!).toBeCloseTo(1);
});
test("rankingPais: artista local sobe no próprio país", () => {
  const pesos: Pesos = new Map([["AUSTRÁLIA", 0.025], ["BRASIL", 0.072]]);
  const ms = [
    { tituloNorm: "a", titulo: "X - A", artistaPrincipal: "X", valor: 1000, nacionalidades: new Set<string>() },
    { tituloNorm: "b", titulo: "Amanda Brokne - B", artistaPrincipal: "Amanda Brokne", valor: 800, nacionalidades: new Set(["AUSTRÁLIA"]) },
  ];
  expect(rankingPais(ms, pesos, "AUSTRÁLIA", 0.2, 50)[0].tituloNorm).toBe("b");
  expect(rankingPais(ms, pesos, "BRASIL", 0.2, 50)[0].tituloNorm).toBe("a");
});
```
